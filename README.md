# primate-recursion-calibration

A pre-registered calibration of the held-out likelihood test behind the 2026 preprint
"Supra-regular recursion in primate vocal sequences" (Nitschke et al., bioRxiv
[10.64898/2026.09.19.752870](https://www.biorxiv.org/content/10.64898/2026.09.19.752870v1)),
which reports that bonobo, olive colobus and marmoset call sequences contain parts "most likely
generated by supra-regular recursive grammars".

**Question.** Does the test (fully connected PCFG vs n-gram models, share of 20 cross-validation
folds in which the PCFG predicts better) also fire on sources that are *regular* by
construction: a hidden Markov model, or simply the observed marmoset sequences resampled? An
n-gram model is only one kind of regular grammar, every sequence in the public marmoset data
has 9 calls or fewer, and fold signs vary by chance. If regular worlds give the same "about
half the folds" pattern, the published evidence cannot separate recursion from regular
structure.

**The wow, if it holds:** a widely covered claim that monkeys and apes use human-like recursive
grammar would rest on a test that cannot tell recursion from a finite-state source. If the test
passes, that is the first independent calibration supporting the method.

- `PREREG.md`: the registered tests, predictions with probabilities and headline rules
  (registered 2026-11-25, before any model was fitted).
- `grammars.py`: n-gram (ML unigram and modified Kneser-Ney), HMM and CNF PCFG models, batched
  inside-outside and Baum-Welch. numpy only.
- `recursion_test.py`: the pipeline (`real` for the marmoset data, `worlds` for simulated
  worlds).
- `fetch_data.py`: downloads Bosshard et al.'s public OSF file and checks its MD5 (the data are
  not redistributed here).
- Tests: `python -m unittest -v test_grammars test_recursion` (dynamic programmes are checked
  against brute-force sums over hidden paths and parse trees).
